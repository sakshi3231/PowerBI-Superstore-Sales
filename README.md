# Superstore Sales Performance Dashboard

## Description:
This dashboard provides an overview of retail sales performance using Power BI. It highlights key metrics such as Total Customers, Total Sales, Profit, and Items Sold. The dashboard includes interactive filters for Category and Region to explore sales data.

Key insights include:

- Top-selling sub-categories such as Phones and Chairs.
- Segment-wise sales analysis showing Consumer as the leading segment.
- Year-over-year sales trends with a 3-month forecast.
- Top 5 profitable products to support marketing and inventory decisions.
